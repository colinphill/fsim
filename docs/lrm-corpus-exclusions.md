# LRM corpus exclusions

Generated by `python3 scripts/lrm_corpus.py exclusions --out docs/lrm-corpus-exclusions.md`; edit the reasons in `scripts/lrm_corpus.py` and regenerate.

- **not run**: the case is skipped (`skip`), for example because it needs a tool, flag or library outside fsim's scope.
- **out of scope**: the case runs, but a failure is recorded as a skip because it depends on behaviour the IEEE LRMs do not define (another simulator's extension, process-order races, implementation-defined output) or because the source is illegal.

Exclusions never count as closures.
