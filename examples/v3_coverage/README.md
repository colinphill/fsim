# v3 unified coverage example

Run the independently authored SystemVerilog-2023 example from this directory:

```text
fsim run
```

The manifest enables code coverage, while the covergroup contributes
functional coverage to its separate runtime namespace. The
[unified coverage guide](../../docs/code-coverage.md) shows database save,
merge, report, and CI-threshold commands.
